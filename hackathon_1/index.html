Start here

Everything for today is in the shared Drive folder OpenADMET Hackathon!

One-time setup, takes a minute

  1. Open the shared folder link you were given.

  2. Open Notebooks/00_start_here.ipynb.

  3. File → Save a copy in Drive. The shared copy is read-only, so if you skip this you will lose your work when the tab closes.

  4. Work in your copy. Do the same for every notebook you open.

Then

Change CHANGE-ME in the first cell to your pair name and run it. Use the same pair name in every notebook — that is what links your work together, so your split and your saved models follow you from one notebook to the next.

Read README.md for the plan for the day and REPORT_TEMPLATE.md for what you are presenting at the end. Read the report template early; it tells you what to write down as you go.

What is in the folder

Notebooks/  the seven notebooks — start with 00, then 01 and 02, then pick
Data/        the training set and the blinded test set
Setup/       common.py, the shared helper module (you never edit this)
Artifacts/  precomputed descriptors, so you are not waiting on your laptop

If the first cell fails

"Could not find common.py" → you skipped a setup step above.

Anything else → Runtime → Restart session, then re-run from the top. After a restart you have to run the cells above the one you were on.

Notebooks

Work through these in order, then pick

Start with 00 to get on the leaderboard, then move through the rest as time allows. Each one opens directly in Colab.

0Start here

Get a first submission on the leaderboard with the simplest possible model. Then look at the data itself: what was measured, how it was transformed, and how much the compounds drift over time.

Open

1Descriptors and regressors

Compare classical molecular descriptors and fingerprints paired with different regressors to see how much the choice of representation moves predictive performance. It's the first lever most teams pull, and often the one with the biggest early payoff.

Open

2Ensembles

Combine models that fail in different ways to see when an ensemble actually beats its best individual member. The question isn't which model wins alone, but how correlated your models' errors are — before you spend a submission finding out.

Open

3External data

Pull in public ADMET data from sources like TDC, Polaris, and ChEMBL to expand your training set beyond what's provided. The catch: an assay value measured by someone else isn't the same measurement as yours, and this notebook walks through making them comparable.

Open

4Multitask learning with Chemprop

Train one Chemprop model with a shared molecular encoder and nine task-specific output heads, instead of nine separate models. Data-rich endpoints end up improving the shared representation that data-poor endpoints then get to use for free.

Open

5Pretrained models

Fine-tune CheMeleon, a Chemprop encoder pretrained on a large molecular corpus, and try TabPFN, a tabular transformer that predicts on your data without training on it at all. Everything here is single-task, so you can see the effect of pretraining on its own before combining it with multitask learning.
