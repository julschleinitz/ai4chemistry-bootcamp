Why a Threshold Matters

A classifier rarely outputs a label directly — it outputs a continuous score: a hit-probability from a virtual screen, a blood–brain-barrier permeability estimate, a toxicity risk. Turning that score into a yes/no call requires picking a threshold, and where you set it trades false positives against false negatives. The ROC curve (Receiver Operating Characteristic) plots the True Positive Rate against the False Positive Rate as that threshold sweeps across every possible value; the AUC (Area Under the Curve) summarizes classifier quality independent of any single threshold choice.

Key Formulas

TPR (sensitivity) = TP / (TP + FN)
FPR (1 − specificity) = FP / (FP + TN)
Precision = TP / (TP + FP)
Accuracy = (TP + TN) / (TP + TN + FP + FN)
AUC = P( scorepositive > scorenegative ) for a randomly drawn positive/negative pair

Because AUC integrates over every possible threshold, it doesn't depend on how the scores are scaled, or on where you'd eventually set the cutoff — that choice comes later, driven by the relative cost of a false positive vs. a false negative in your specific screening campaign.
