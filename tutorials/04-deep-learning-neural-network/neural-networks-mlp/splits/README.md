# Fixed Split Files

Use this directory to publish fixed split membership before the tutorial.

## Required files for students

- `train.csv`
- `val.csv`
- `test.csv`

Each file must contain one column named `sample_id`.

## Setup

1. Replace template files with real split files.
2. Keep the same split files for all groups.
3. Version changes by updating `split_version` in submissions.
