Model Training & Evaluation

A hands-on lab on the BBBP blood–brain barrier dataset: random vs. scaffold vs. temporal splitting, nested cross-validation, learning/validation curves, and a real data-leakage bug to find and fix.

What you will learn

  • Split the BBBP dataset using random, scaffold (Bemis–Murcko), and simulated temporal strategies with RDKit and scikit-learn
  • Implement nested cross-validation to tune Random Forest hyperparameters without touching the test set
  • Plot learning curves and validation curves to diagnose the bias–variance regime of a model
  • Find and fix a "fit-before-split" data leakage bug, and see why its impact differs across model types
  • Extend a greedy scaffold splitter to balance class rate across folds, not just fold size

Instructions

Getting started

Open the Colab notebook using the button above. Run each cell in order; cells marked ### EXERCISE require you to fill in code — everything else is provided scaffolding.

  1. Set up the environment. Install rdkit, scikit-learn, pandas, and matplotlib. Confirm the setup cell prints Setup OK.

  2. Explore the dataset. Load the 2050-molecule BBBP (blood–brain barrier permeability) table. Exercise 2.1: count duplicated raw vs. canonical SMILES, flag duplicate groups with conflicting labels, and resolve them before splitting. Then plot the class balance.

  3. Implement splitting strategies. Featurize once with 1024-bit Morgan fingerprints, then complete three splits: 3a an 80/20 stratified random split; 3b a scaffold split that computes each molecule's Bemis–Murcko scaffold and greedily packs whole scaffold groups (largest first, shuffled for tie-breaking) into train/valid/test; 3c a temporal split on a provided simulated sim_year column (the public BBBP table has no real publication dates). Compare class distributions and visualize both splits in PCA space.

  4. Tune with nested cross-validation. Exercise 4: fill in a small hyperparameter grid for a RandomForestClassifier (n_estimators, max_depth, min_samples_leaf) and complete nested_cv_auc — an inner GridSearchCV fit on the training indices only, scored once on held-out test indices.

  5. Diagnose your model. On the scaffold split's training set, plot a learning curve (training size vs. AUC) in 5a and a validation curve (max_depth vs. AUC) in 5b. Identify the bias–variance regime your model is in.

  6. Find and fix the leakage bug. Exercise 6: implement a buggy branch that fits StandardScaler on train+test stacked together, and a fixed branch that fits it on the training data only. Compare AUC for a Random Forest, then 6b for a KNN and a Logistic Regression model.

  7. Challenge: balanced scaffold folds. Exercise 7: extend the greedy scaffold packer from step 3 into a k-fold splitter (balanced_scaffold_folds) that also balances each fold's positive rate, not just its size.
