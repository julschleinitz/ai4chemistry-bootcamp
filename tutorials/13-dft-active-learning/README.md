# Tutorial 13 — Active Learning on Carboxylic Acid DFT Descriptors

Paired with **Lecture 13 (Active Learning)**. 90 minutes, Colab-first.

Students train a Chemprop D-MPNN to predict **156 conformer-ensemble DFT descriptors** for
commercially available carboxylic acids, buying labels for **at most 600** of ~6,528 pool
molecules, and are scored on a hidden, scaffold-disjoint test set for **accuracy and uncertainty
calibration**.

The labels are the published descriptors from Haas *et al.*, *Digital Discovery* **2025**, *4*,
222 (CC BY 4.0), fetched from the open MolSSI API. **Nothing here recomputes chemistry** — the
authors spent over 1,000,000 CPU hours, about **117 CPU-hours per molecule**, which is what makes
a 600-label budget mean something.

## Before the bootcamp

One environment. No GPU, no quantum chemistry.

```bash
python -m venv ~/envs/al && source ~/envs/al/bin/activate
pip install chemprop==2.3.1 rdkit scikit-learn matplotlib pandas
```

```bash
cd instructor
./run_all.sh smoke     # 300 molecules end-to-end, ~2 min -- proves the whole path works
./run_all.sh full      # all 8,528, ~15 min, almost all of it API paging
```

`run_all.sh` calls `01_fetch_dft_labels.py --verify-header` first, which asserts the upstream
schema still matches `descriptor_spec.py`. If MolSSI changes a column you get a clear error rather
than silently shifted data. API responses are cached per 100-molecule chunk in `data/api_cache/`,
so re-runs are free and an interrupted run resumes.

Then commit the student bundle — the notebook downloads it from raw.githubusercontent.com at
runtime, so it must be on `main` before class:

```bash
git add data/student && git commit -m "tutorial 13: student bundle"
```

**Never commit `data/instructor/`.** It holds the hidden test labels; the local `.gitignore`
excludes it. Check `git status` before pushing.

Leaderboard setup (Sheet + Apps Script + Drive folder): **[`leaderboard/SETUP.md`](leaderboard/SETUP.md)**.
Both the notebook and the page ship with `PASTE_..._HERE` placeholders and degrade gracefully
until you fill them in, so the tutorial is fully usable without the Sheet.

Sanity check at any time, with no heavy dependencies:

```bash
python tests/test_logic.py
```

## Four things to say out loud

1. **The oracle cost is real.** Section (a) prints ~117 CPU-hours per label before students spend
   anything. A wasted batch of 50 is ~240 CPU-days.
2. **The random baseline is mandatory.** Section (d) runs it first, and section (c) measures
   seed-to-seed variance so students can tell whether their "improvement" is real. Lecture 13 §8
   exists because this step is usually skipped.
3. **`max_variance` over 156 mixed-unit targets is worse than random**, because a raw sum of
   standard deviations is dominated by `volume` (~2,000 Bohr³) and `IR_freq` (~1,800 cm⁻¹). The
   one-line fix, `max_variance_scaled`, is the tutorial's "aha".
4. **The budget is a rule, not a lock.** The sealed label file is a speed bump;
   `score_submissions.py --audit` compares each model's error on its purchased molecules against
   500 pool molecules absent from its log. Say this at the start, not at the leaderboard.

## Two caveats to state before showing results

**The live board is not the result.** It carries self-reported *dev* scores. The real ranking comes
from `score_submissions.py` on the hidden test set. Teams reorder between the two, and that
reordering is the closing lesson.

**The published GNN comparison is not like-for-like.** Their numbers come from a **random** split
with **7,290** training molecules; this test set is scaffold-disjoint and the budget is 600. Their
numbers are a ceiling — a ratio of 2× is a good result.
