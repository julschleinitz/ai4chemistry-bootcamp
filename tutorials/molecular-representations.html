Tutorial 1

Molecular Representations

Build, visualize, and compare five molecule-to-vector representations — physicochemical descriptors, Morgan fingerprints, an xtb solvation-energy descriptor, a ChemBERTa foundation-model embedding, and molecular graphs — using the ESOL solubility dataset.

What you will learn

  • Understand why PCA needs standardized, decorrelated features — and compare PCA, t-SNE, and UMAP on the same data
  • Build and quantitatively evaluate a hand-designed molecular representation, then compare it to an expert-defined descriptor set
  • Compute Morgan fingerprints with RDKit, and clean up sparse/zero-variance bits before analysis
  • Featurize molecules with an xtb gas-phase-vs-solvation energy descriptor and a pretrained ChemBERTa embedding
  • Define a molecular graph with real bond-type edges, and see why variable graph size forces a pooling step before visualization

Instructions

Getting started

Open the Colab notebook using the button above. The notebook is structured into clearly labelled sections. Run each cell in order; cells marked Exercise require you to fill in code. Stuck on one? The solutions notebook (see Resources below) has a worked example for every exercise.

  1. RDKit setup. Load the ESOL dataset and get comfortable with RDKit's Mol objects, drawing, and the Descriptors module.

  2. Dimensionality reduction. Build the reusable plot_chemical_space/evaluate_representation_knn toolkit, and see why standardization, correlated-feature removal, and the choice of PCA vs. t-SNE vs. UMAP all change what the resulting 2D map looks like.

  3. Data visualization example. Run the toolkit end-to-end on a trivial representation to confirm the pipeline works.

  4. Build your own representation. Hypothesize which molecular properties drive solubility, implement compute_custom_features, and see how it scores.

  5. Compare with an expert-defined representation. Build RDKit's physicochemical descriptors (plus charge/pKa) and compare against your own.

  6. Morgan fingerprints. Compute ECFP4 fingerprints, see how sparse they are, and remove zero-variance bits before visualizing.

  7. Featurize with xtb. Run a real gas-phase-vs-solvation single-point calculation live on 20 molecules, then switch to a precomputed CSV for the full dataset.

  8. Featurize with ChemBERTa. Extract a frozen embedding per molecule from a pretrained foundation model and visualize its chemical space.

  9. Graph definition. Implement bond-type edge features, compare two molecules' graph sizes directly, and see why pooling is needed before a graph can be visualized like every other representation.
