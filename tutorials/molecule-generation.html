Molecular Generation

Search chemical space against a real (cheaply-configured) protein-ligand docking oracle — random search, a genetic algorithm, and a surrogate-guided active-learning loop, compared at the same oracle-call budget, then submitted to a leaderboard that's graded independently and accurately.

What you will learn

  • Build a cheap, real protein-ligand docking oracle (smina, EGFR / PDB 2ITO) and wrap it in a single evaluate() function every method below calls
  • Implement and compare three molecule-search strategies at the same oracle-call budget: random search, a genetic algorithm, and a surrogate-guided active-learning loop
  • See how a cheap machine-learned surrogate with an uncertainty-aware acquisition score can cut how often you need to call an expensive oracle — a simplified Bayesian-optimization loop
  • Understand why optimizing a single objective (docking score alone) is risky, and extend the search to drug-likeness (QED) and structural-alert objectives
  • Submit your single best candidate to a live, independently-graded class leaderboard, complete with a 3D view of the current best binder

Instructions

Getting started

Open the Colab notebook using the button above. Run each cell in order; cells marked Exercise require you to fill in code.

  1. Set up the oracle (a). Install smina/openbabel via condacolab, fetch and parse the EGFR (2ITO) structure, define the binding pocket, and benchmark cheap vs. the docking tutorial's own accurate settings.

  2. Random search (b). Generate random SELFIES-based molecules and dock them — every string decodes to a valid molecule by construction, so nothing is wasted on invalid candidates. This is your undirected baseline.

  3. Genetic algorithm (c). Implement mutation and tournament selection; evolve a population against the same oracle-call budget as random search.

  4. Surrogate-guided active learning (d). Train a random-forest surrogate on Morgan fingerprints, and use an uncertainty-aware acquisition score to decide which candidates are worth a real docking call.

  5. Challenge + bonus. Submit your single best candidate's SMILES to the leaderboard — it's graded independently, at the docking tutorial's own accurate settings, not your cheap exploration numbers. Then, in the bonus section, see how adding QED and toxicity-alert objectives changes what "best" means.
