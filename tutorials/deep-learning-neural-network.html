Neural Networks in Practice

Predict Tox21 toxicity with an MLP built from scratch in PyTorch — choose a fingerprint featurization, fight overfitting with regularization, question architecture against dataset size, run a fixed-split hyperparameter search, and extend to multi-task learning.

What you will learn

  • Get to know the Tox21 toxicity dataset — 12 sparse-labeled assays — and pick a featurization by visualizing and quantitatively evaluating it
  • Build an MLP from scratch in PyTorch, starting from the simplest possible single-hidden-layer network and generalizing it into a configurable model
  • Implement the training loop by hand: forward pass, loss, backpropagation, optimizer updates, and early stopping on a validation metric
  • Recognize overfitting in a learning curve and fight it with regularization — early stopping, weight decay, and dropout
  • Question whether a bigger architecture is justified by the training set size, and compare learning curves across hyperparameters
  • Run a fixed train/val/test hyperparameter search and submit a standardized payload for the class Pareto-front analysis
  • Advanced: extend the model to multi-task learning across all 12 Tox21 assays with a masked loss

Instructions

Getting started

Open the Colab notebook using the button above. The notebook is structured as ten exercises, in order. Run each cell in order; cells marked Exercise require you to fill in code. Stuck on one? The solutions notebook (see Resources below) has a worked example for every exercise.

  1. Introduce the Tox21 dataset. Load dataset.csv and look at per-task label counts, positive rates, and the missing-label pattern across all 12 assays.

  2. Visualize and choose a featurization. Compute Morgan fingerprints from SMILES, project them to 2D with PCA, sanity-check them with a quick k-NN classifier, and use Tanimoto similarity to compare positively- vs. negatively-labeled molecules.

  3. Introduce the neural network. Build the simplest possible single-hidden-layer network, write one manual optimization cycle by hand, then generalize it into the configurable MolecularMLP class.

  4. Train a baseline model. Load the fixed train/val/test split for one Tox21 task and train a first MLP configuration end to end.

  5. Regularization. Recognize the overfitting in the baseline's learning curve, then fight it with dropout, weight decay, and tighter early stopping.

  6. Question architecture vs. dataset size. Sweep model capacity (tiny/medium/large) at fixed dataset size, see where overfitting kicks in, and quantify how much a single score varies by weight-init seed vs. by train/val/test split.

  7. Visualize learning curves vs. hyperparameters. Overlay validation curves across a swept hyperparameter (e.g. learning rate).

  8. Run a hyperparameter search. Sweep a small grid, select the best run by validation score only, and plot the efficiency/performance frontier.

  9. Draw conclusions. Plot an ROC curve for the best model and submit your run to the class leaderboard.

  10. Advanced: multi-task Tox21. Train one model across all 12 assays at once with a masked loss, and compare its score on your primary task against the single-task baseline.

Questions
